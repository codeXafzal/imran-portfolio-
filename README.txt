IMRAN KHAN — PORTFOLIO WEBSITE

FILES
- index.html   Page content and structure
- styles.css   Responsive visual design and animations
- script.js    Navigation, theme switch, resume preview/print and scroll effects

RUN LOCALLY
1. Keep all three files in the same folder.
2. Open index.html in a modern browser.

DEPLOY TO NETLIFY (NO GITHUB REQUIRED)
1. Extract the ZIP file.
2. Sign in to Netlify and choose the manual deploy / Netlify Drop option.
3. Upload the extracted folder that contains index.html, styles.css and script.js.
4. Netlify will publish the static site and provide a public URL.

CONTACT LINKS
WhatsApp, email and click-to-call links are already connected using the contact details in the supplied resume.
To edit them, search for the contact details and wa.me link in index.html.

RESUME PDF
The Download PDF button opens the browser's print dialog. Choose “Save as PDF”.
The print stylesheet formats only the resume, not the full portfolio page.

NOTES
- No framework, backend, GitHub repository or Netlify-specific configuration is required.
- The mobile resume preview is a compact inset dialog with its own scrolling area.
- The site respects the visitor's reduced-motion accessibility preference.
- The NBFC company name and social profile links were not supplied, so they have not been invented.
